# Your own Steel Ball Run artwork

Drop images here and the site uses them; with none here, the drawn versions show instead.
Everything in this folder except this file is git-ignored, so your images stay on your computer.

| File         | Where it shows                                  |
|--------------|-------------------------------------------------|
| `logo.png`   | Top of the race route, in place of the wordmark |
| `hero.png`   | Beside the clock on the Now page                |
| `d4c.png`    | Over the flags during the D4C easter egg        |
| `wanted.png` | Faintly behind every WANTED poster on About     |
